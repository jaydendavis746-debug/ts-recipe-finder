# ts-recipe-finder

## App Purpose
To find recipes based off of your favourite ingredient.

## Tech Stack
- React
- Typescript
- Playwright
- Jest
- Vitest

## Instillation and running
- `git clone` this repo onto your local machine.
- `npm i` to install the required dependencies.
- `npm build` to build the application for it to run.
- `npm run dev` to run the application in developer mode.

## Testing

### Component Testing

- `npm run test` to run the component tests.
- `npm run coverage` to see the passing coverage of component tests.
